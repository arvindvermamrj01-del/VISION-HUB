VISION HUB — setup files

Upload these three files/folders into the ROOT of your existing GitHub repository:
- css/style.css
- js/data.js
- js/app.js

Keep your existing index.html in the repository root.

Important:
- This is a frontend demo. Watchlist and requests are saved only in the visitor's browser.
- Login, registration, admin publishing, shared request storage and music management are NOT connected to a backend.
- Do not collect real passwords until Supabase Auth (or another secure backend) is configured.
- Only add trailers, streaming destinations, music and media that you own or are authorised to distribute.
- GitHub Pages can host the static frontend, but it is not a database or secure authentication server.

After uploading, open the GitHub Pages website and hard-refresh it. If Pages is not enabled:
Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.
